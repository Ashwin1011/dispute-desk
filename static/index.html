DisputeDesk

A LangGraph payment-dispute copilot: retrieves evidence, checks for fraud, drafts a reply, fact-checks itself, and only pulls in a human when it actually needs one.

1. Run it

This page is served by the same FastAPI app as the API it talks to — nothing else to configure, just get the server running.

Without Docker
  1. Copy .env.example to .env and fill in ANTHROPIC_API_KEY / TAVILY_API_KEY (and the LANGFUSE_* keys if you want tracing).
  2. uv sync
  3. Make sure Postgres is running locally with the schema applied and evidence seeded (uv run python seed_evidence.py, one-time).
  4. uv run uvicorn disputedesk:app --reload
  5. Open this page (you're probably already here).
With Docker
  1. docker compose up -d --build
  2. First time only: apply schema.sql and run seed_evidence.py inside the app container.
  3. Open http://localhost:8000/.
